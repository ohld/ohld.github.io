«Пытался разные скиллы юзать, всё равно слопно достаточно получается», — [написал участник моего чата](https://t.me/ohld_chat/44546) про лендинги, которые делал через Claude. Знакомое ощущение. Карточки аккуратные, градиент красивый, а сайт ты уже видел раз сто.

Для нового сайта я бы взял frontend-design, приложил фотографии продукта и попросил показать один экран. Если экран уже есть и на нём теряется кнопка записи, я бы начал с Impeccable. Ему можно показать кнопку и спросить, куда вообще смотрит человек, когда открывает страницу.

В таблице — восемь скиллов из семи репозиториев. Частоту обновлений я оценил по коммитам в основной ветке каждого проекта за три месяца, по состоянию на ноябрь 2026.

## Как установить скиллы в Claude Code и Codex

Скилл — папка с [инструкцией SKILL.md](/ru/articles/kak-pravilno-pisat-skilly-claude-code-7-oshibok/). По её описанию агент решает, когда она ему пригодится. Если ты только собираешь свой набор инструментов, вот [мой сетап Claude Code](/claude-code-nastrojka-mcp-hooks-skills-2026/) и [скиллы и MCP, которыми я пользуюсь](/luchshie-skills-mcp-claude-code-agent-browser/).

Открой терминал в папке проекта. Для команд ниже нужен Node.js. В установщике `npx skills add` выбери Claude Code, Codex или оба. Можно сразу дописать к команде `-a claude-code` или `-a codex`. Без глобального флага скилл установится в проект.

Открой новую сессию. В Claude Code набери `/имя-скилла`, в Codex — `$имя-скилла` или выбери его в меню `/skills`. Если агент показывает имя с префиксом плагина, используй его целиком. Примеры запросов ниже работают в обоих агентах.

## Первый экран и его разбор

### 1. frontend-design — первый экран сайта

[frontend-design от Anthropic](https://github.com/anthropics/skills/tree/main/skills/frontend-design) помогает выбрать, что человек увидит первым. Для отеля у моря это может быть фотография вида из номера и кнопка «Выбрать даты». Дай агенту свои фотографии, скажи, кто бронирует номер, и попроси показать первый экран на телефоне. Так у него появится материал, вокруг которого можно собрать страницу.

```bash
npx skills add anthropics/skills --skill frontend-design
```

В чате frontend-design [советовали и для Codex](https://t.me/ohld_chat/35009). Если выбираешь между агентами, я разбирал, [когда беру Claude Code, а когда Codex](/ru/blog/claude-code-vs-codex-perehod/).

**Когда пропустить.** Добавляешь поле в готовую форму. Возьми соседнее поле за образец, у него уже есть шрифт, отступы и состояние ошибки.

### 2. Impeccable — разбор готовой страницы

[Impeccable](https://github.com/pbakaus/impeccable) я бы дал экран с тарифами. Спроси через `critique`, что первым бросается в глаза. Бывает, что цену на карточке ещё надо найти, зато подпись «Популярный» видно из соседней комнаты. Дальше можно отдельно поправить шрифты через `typeset` или отступы через `layout`. Именно этот скилл вместе с Emil и UI UX Pro Max [посоветовали в чате](https://t.me/ohld_chat/52589).

```bash
npx impeccable install
```

Выбери агента и установку в проект. В Claude Code вызови `/impeccable init`, в Codex — `$impeccable init`, чтобы описать продукт. Затем дай команду `/impeccable critique блок тарифов` или `$impeccable critique блок тарифов`. Если установщик добавил автоматическую проверку дизайна, подтверди проектный хук в Codex через `/hooks`. Вручную скилл можно вызвать и без хука.

**Когда пропустить.** Ты ещё решаешь, что предложить на первом экране — демо или оплату. Сначала выбери действие, тогда станет понятно, какую кнопку выделить.

## Когда экран уже работает

### 3. emil-design-eng — нажатия и переходы

[Скилл Эмиля Ковальски](https://github.com/emilkowalski/skills) пригодится, когда на скриншоте всё хорошо, а пользоваться неудобно. Например, переключаешь вкладки и каждый раз ждёшь, пока доиграет анимация. Попроси агента убрать задержку и показать, как меню открывается мышью и с клавиатуры. Тут стоит потыкать оба варианта в браузере. Открой меню три раза подряд. При первом открытии анимация помогает заметить, откуда появилась панель. К третьему уже хорошо чувствуешь, в какой момент она начинает мешать.

```bash
npx skills add emilkowalski/skills --skill emil-design-eng
```

**Когда пропустить.** Из названий вкладок непонятно, что внутри. Сначала перепиши подписи.

### 4. better-ui — иконки, скругления и тени

[better-ui Якуба Крехела](https://github.com/jakubkrehel/skills/tree/main/skills/better-ui) помогает с деталями одного компонента. Иконка Play по координатам стоит ровно в центре кнопки, а на глаз съехала влево. Или у вложенной карточки углы круглее, чем у внешней. Покажи агенту панель настроек, попроси проверить выравнивание и сохранить плотность интерфейса. На одном компоненте я бы пробовал Emil и better-ui по очереди в отдельных версиях. Иначе потом попробуй разбери, кто из них поменял поведение кнопки.

```bash
npx skills add jakubkrehel/skills --skill better-ui
```

**Когда пропустить.** Нужен аудит доступности всей страницы. Ровная иконка ещё ничего не говорит о том, можно ли добраться до кнопки с клавиатуры.

## Портфолио и продуктовые интерфейсы

### 5. design-taste-frontend — портфолио вокруг фотографий

[Taste Skill](https://github.com/Leonxlnx/taste-skill) ведёт агента от выбора композиции до проверки в браузере. Я бы попробовал его на сайте студии керамики. Приложи снимки чашек и мастерской, попроси сохранить цвета глазури. Открой первый экран на телефоне и посмотри, что осталось от фотографий после обрезки.

```bash
npx skills add Leonxlnx/taste-skill --skill design-taste-frontend
```

Понадобятся Node.js 22+ и Chrome, Edge или Chromium. В чате [рекомендовали Taste v2](https://t.me/ohld_chat/52591). Команда выше ставит скилл из репозитория без привязки к той версии.

**Когда пропустить.** У тебя есть макет, который нужно точно сверстать. Выбирать композицию заново здесь незачем.

### 6. UI UX Pro Max — одна дизайн-система для нескольких экранов

[UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) подбирает палитру, шрифты и компоненты из каталога. Например, делаешь сервис бронирования на React. Попроси агента показать одну карточку с длинным названием и одну форму с ошибкой. После этого проще решить, годится ли набор для поиска, записи и оплаты. Посмотри, хватает ли места для названия в две строки и видно ли, к какому полю относится ошибка. Если устраивает, попроси агента использовать те же компоненты на остальных экранах.

В проекте для Claude Code выполни эту команду.

```bash
npx ui-ux-pro-max-cli init --ai claude
```

В проекте для Codex укажи другого агента.

```bash
npx ui-ux-pro-max-cli init --ai codex
```

Для поиска по каталогам нужен Python 3.

**Когда пропустить.** Характер сайта задают фотографии или иллюстрации. Начни с них, палитру подберёшь по ходу.

## Для игр: графика в одном стиле и удобный HUD

### 7. create-game-assets — спрайты в одном стиле

В [обсуждении игры для Яндекс Игр](https://t.me/ohld_chat/57467) Арсений поделился инструментами для графики, интерфейсов и звука. Из его набора я бы взял два скилла. Первый, [create-game-assets](https://github.com/gamedev-skills/awesome-gamedev-agent-skills/tree/main/skills/disciplines/create-game-assets), помогает нарисовать героя и противников так, чтобы они выглядели персонажами одной игры.

```bash
npx skills add gamedev-skills/awesome-gamedev-agent-skills --skill create-game-assets
```

Начни с одного героя. Зафиксируй палитру, ракурс и размер спрайта, посмотри на него прямо на игровом фоне. Если контур читается, дай этот образец агенту для остальных персонажей. Для самих картинок подключи инструмент генерации изображений.

**Когда пропустить.** Спрайты уже готовы и осталось импортировать их в движок.

### 8. game-ui-ux — игровое меню и HUD

[game-ui-ux](https://github.com/gamedev-skills/awesome-gamedev-agent-skills/tree/main/skills/disciplines/game-ui-ux) помогает проверить меню и HUD — здоровье, счёт и другие показатели поверх игры. Для [игры в Telegram Mini App](/ru/blog/vibecoding-telegram-mini-app-claude-code/) я бы начал с телефона. Видно ли счёт? Можно ли нажать паузу большим пальцем? Если есть управление с геймпада, открой меню и проверь, куда уходит фокус после закрытия.

```bash
npx skills add gamedev-skills/awesome-gamedev-agent-skills --skill game-ui-ux
```

**Когда пропустить.** Меню работает, а проблема в балансе уровня или в том, что герой сливается с фоном.

## Как совместить скиллы в одной задаче

Я [писал про «покажи, не рассказывай»](https://t.me/danokhlopkov/1612). То же самое с дизайном. Подставь свой продукт, приложи референс и попроси один экран, который можно открыть и потыкать.

```text
Используй frontend-design.
Делаем сайт маленькой студии керамики. Цель — записаться на занятие.
Вот фотографии работ и референс. Объясни, что берёшь из референса.
Сохрани существующий стек проекта.
Сначала сделай первый экран и карточку занятия, без остальных страниц.
Покажи в браузере на ширине 390 и 1440 px.
Проверь длинное название занятия и кнопку записи.
После моего выбора зафиксируй цвета, шрифты и отступы.
```

Открой оба размера и попробуй записаться. На десктопе карточка занятия и кнопка могут стоять рядом, а на телефоне между ними вдруг окажется фотография во весь экран. Если на телефоне кнопку приходится искать, покажи этот экран Impeccable и попроси назвать три вещи, которые отвлекают от записи.
