## Как сделать карту постов своего Telegram-канала

Каждая точка — пост. Похожие по смыслу посты лежат рядом. Выгрузи историю своего канала в JSON через Telegram Desktop и дай файл Claude Code или Codex с таким промптом.

```
Из JSON моего публичного Telegram-канала возьми текст, дату и ID постов. Посчитай и нормализуй эмбеддинги текстов, разбей их на 12 тем через KMeans и назови темы по примерам постов. Для каждого поста найди 6 соседей по косинусному сходству. Разложи точки на плоскости через UMAP с косинусной метрикой. Собери статическую карту с поиском. Цвет точки — тема, по клику покажи текст, ссылку на пост и соседей.
```
